# Roadmap

- [ ] إعادة تصميم دورات تحسين المستوى واللغات فقط: مدة زمنية وأسعار الدورات والتجديد، مع تسجيل الحصص فعلياً ودون تغيير دعم المدرسة أو الورشات؛ بانتظار اعتماد المستخدم للملخص قبل التنفيذ.

- [ ] Teacher-only sign-in link tied to admin browser presence, code-based initial credentials and required password change.
- [ ] Teacher portal with access restricted to the linked teacher's own records; verify isolation and closure.

- [x] Groups capped at 15 with a professional "group full" notice
- [x] Waiting list (by subject + age category) with "group ready" alert at 8 students
- [x] Group age categories: 5–8, 9–10, 11–13, 14–16, 17+

- [x] Built-in director account admin/admin works on every fresh copy (no registration).

- [x] Create admin account (email = password as requested)
- [x] Timetable page: weekly grid per teacher (group, subject, room) + live current-session panel (attendance count, countdown) + next-session panel
- [x] Group attendance page: print monthly sheet (ح/غ), fixed columns = monthly sessions setting, dates from recorded sessions
- [x] Teacher gender (أستاذ/أستاذة) on every page and printout
- [x] Workshop attendance sheet: 1 session, "الحالة" column, portrait, 2 tables × 20 per page
- [x] Weekly group attendance sheet: portrait too (8 narrower columns)
- [x] Users button in Settings: director (all access) / secretary (no monthly income, payroll, finance, settings)
- [x] No self sign-up: director creates accounts; username + password sign-in page (first-time admin/admin hint); every user changes own password (Settings for director, «حسابي» for all)
- [x] Passwords: free choice, minimum 6 characters (no strength check)
